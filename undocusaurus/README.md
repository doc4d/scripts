# undocusaurus

some script to apply to a folder with markdown files, to convert from docusaurus format to 4d project/component doc

| scripts | description | 
| - | - | 
| rename_md_files.py| Uses special headers to rename files | 
| remove_md_headers.py| Removes headers from Markdown files | 
| fix_markdown_links.py| Fixes Markdown links based on files in the folder | 
| add_header_if_missing.py| Add a main header with file name if missing | 
| remove_details_block.py| Remove history detail block | 

launch_script.py to launch them all in order

example of path to apply https://github.com/doc4d/docs/tree/main/docs/ViewPro/commands
